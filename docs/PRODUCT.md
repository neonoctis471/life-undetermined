# 人生未定式

**把知乎网友真实走过的人生经验，变成你可以亲自验证、对照和讨论的平行人生。**

*毕业后的五年，你可以走两遍。*

在线体验：**https://indeterminate.eilnoctis.com**
单局时长约 8–10 分钟，手机可玩，无需注册登录。

---

## 一句话

这是一个把「毕业后该怎么选」这件事，从**给建议**变成**让你先走一遍**的互动叙事游戏：你做三次选择，看着它们变成五年的人生，然后回到其中任意一次决定，换一个选择，把两段人生并排放在一起看。

它不给你答案，也不评判哪条路更好——它让你看见**选择是怎么长成生活的**。

---

## 为什么做这个

「毕业后该找工作还是考研」「要不要回家」「自媒体能做吗」是知乎上最密集的一类提问。这类问题的真实困难不在于缺少建议——建议太多了——而在于：

1. **建议是别人的语境。** 回答者的家庭、专业、经济条件和你不一样，但答案往往被当成通用结论。
2. **代价是看不见的。** 你能读到「我选了 A，现在很好」，读不到「选 A 的那五年，B 那边会发生什么」。
3. **没有人能真的重来一次。** 而「如果当时……」恰恰是这件事上最强烈的情绪。

这个作品把这三点做成了玩法：知乎上过来人的真实经验被摆进你正在面对的那一刻；每个结果都同时写下收获与代价；最后你可以回到任意一次决定，真的再走一遍。

## 玩法

### 序章 · 毕业那天
勾选你打算做的事（找工作 / 考研 / 考公考编 / 留学 / 做自媒体 / 回家发展 / 帮家里经营 / Gap……），勾选你真正看重的（收入和存款 / 稳定和安全感 / 做自己真正喜欢的事 / 离家人近一点……），再用自己的话写下打算。

这一屏还有两块内容：

- **看看大家都在选什么**——四个来自公开调查的真实数字（见下文「数据的处理」）。
- **看看知乎朋友们怎么推荐毕业后的选择**——检索知乎上过来人的真实回答。

AI 把你的输入整理成结构化的「打算」，复述给你确认，确认后才进入推演。

### 三次选择 · 第 8 天 / 第 7 个月 / 第 4 年
每一幕的结构是固定的：

1. **两种可能**——「顺势发展的可能」与「意料之外的变化」，你选一个走进去。
2. **具体情境**——不是抽象的人生岔路，是一个具体的下午：老顾客来找你帮忙拍宣传片，而这周是旺季。情境页可以随时**看看知乎朋友们是怎么选择的**，调出和当前处境相关的真实经验。
3. **你准备怎么办**——几个具体行动，也可以写自己的办法。
4. **后来**——发生了什么、留下了哪些既成事实、收获、代价、**仍然没有答案的部分**，以及「这件事，在你身上留下了什么」。

### 五年以后
时间加速五年，你在同学聚会上被问「你现在平时都在做什么」。屏幕上是你五年的时间线、和五年前你自己写下的那段话。

### 回溯 · 两段人生
这五年里有三次选择，**每一次都可以回去**。挑一次，换一个做法，时间倒回那一天重新往前走。

最后两段人生并排呈现，并分成三栏：

- 因为那个决定逐渐发生变化的
- 一直没有改变的
- 无法归因于你选择的

**最后的比较不是哪个更好。**

## 和知乎生态的结合

这是这个作品的核心，不是装饰功能。

### 真实内容，不是「AI 扮演知乎用户」

所有知乎卡片都来自真实检索结果，每张卡片保留：

- **作者名**（如「快乐鱼鱼 的回答」「管家老二 的文章」）
- **原问题或原文章标题**
- **可点击的原文链接**

当检索不到足够相关的内容时，AI 补充的参考思路会被**明确标注为「AI 参考思路 · 非知乎内容」**，绝不混入知乎卡片冒充真人经验。这条是硬规则，写在代码里也写在测试里。

### 铺在流程前段，而不是结尾的「相关阅读」

知乎内容出现在两个位置，都是玩家**正在做决定**的时刻：

| 位置 | 检索什么 |
|---|---|
| 序章（决定方向之前） | 过来人怎么建议毕业后的选择 |
| 每一幕的情境页（决定行动之前） | 和当前具体处境相关的经验 |

序章那一处是刻意独立出来的：早期版本按玩家勾的具体路径去找「走过这条路的人」，但真正走过同一条路的人很少，检索质量差。改成「过来人怎么建议选」之后，覆盖面和相关度都显著变好。

### 结构化重述，降低阅读成本

原文常常几千字。每张卡片把它压成玩家在那一刻真正需要的五项：

- **当时条件**——作者当时的处境
- **作者做了什么**
- **后来发生什么**
- **与你相似**——为什么这条经验对你成立
- **与你不同**——为什么不能照搬

「与你不同」这一项是刻意加的：它直接对抗开头说的第一个问题——把别人语境下的结论当通用答案。

## 几个刻意的设计决定

### 没有分数、等级、徽章、经验条

整个作品里没有任何一处给你的人生打分。没有「成就解锁」，没有「+5 沟通能力」，没有升级动画。

理由很简单：一旦引入分数，「哪条路更好」就有了答案，而这个作品的全部主张是它没有答案。

### 「发生了什么」和「留下了什么」是两层，不能混

每个结果分成两部分：

- **现在真正发生了**——既成事实，写进状态，后面的剧情必须建立在它之上，不可撤销。
- **这件事，在你身上留下了什么**——处理事情的方式、新的视角、对自己的了解、付出的代价、暴露出的问题、第一次……每一条都要能追溯到上面的事实。

第二层有严格约束：**不写鸡汤，不总结「你是一个怎样的人」**，且区分三种时间尺度（当下 / 持续 / 可能）。「可能」那一档必须用概率表达，并在界面上弱化呈现——因为它还没发生。

### 等待是设计对象，不是缺陷

五年加速至少 5 秒，回溯至少 7 秒。这两处**不做成加载动画，也不缩短**——时间流逝需要被感觉到。

### 数据的处理

「看看大家都在选什么」只放**能核实来源的数字**，每个数字都标注年份、调查名称、来源媒体和可点击的原文链接。

拿不到合规来源的数据，界面显示「暂无已验证数据」，**不编造百分比**，也不把几个独立的单选比例拼成一个看起来完整的饼图（那四个数字来自可多选的题目，加起来超过 100%，测试里专门有一条断言防止后来的人把它改回「分布」）。

## 技术实现

| 项目 | 说明 |
|---|---|
| 框架 | Next.js 16（App Router）、React 19、TypeScript |
| 校验 | zod v4，六类领域契约 |
| 依赖 | 无 CSS 框架、无动画库、无状态管理库 |
| 部署 | Vercel，自定义域名，中国大陆可直连 |

### 状态机是权威，AI 只是候选内容提供者

这是架构上最重要的一条：**AI 和知乎返回的都只是候选内容，只有游戏状态机能改变权威状态。**

模型输出要穿过两层：先用宽松 schema 接住（容忍模型的格式波动），经过规范化（补 ID、时间戳、因果证据、裁剪超长字段），再用严格的领域 schema 做最终闸门。过不了就拒绝写入。

因果完整性也在这一层校验：每条既成事实必须声明它由哪个决定引起、依赖哪些更早的事实——这是「回溯」能够成立的前提。回到第 8 天时，第 7 个月和第 4 年的事实必须**不存在**，而不是被忽略。

### 回溯怎么保证正确

每一次决定被记录时，系统同时保存一份**决策前快照**：当时的打算、当时已经发生的全部事实。三次决定就有三份快照，与决定一一对应。

你选择回到哪一次，就用哪一份快照去推演——回到第 8 天看到 0 条既成事实，第 7 个月看到 1 条，第 4 年看到 2 条。快照由程序从权威状态确定性地构建，**不经过 AI**，并且引擎会校验它确实对应那一次决定、事实列表确实等于决策前的状态，对不上直接拒绝。

### 降级与隐私

- AI 不可用时，四类操作各有保守模板兜底，界面**如实标注**「保守模板（AI 暂不可用）」，不假装正常。
- 知乎检索失败不阻塞主流程，面板直接隐藏或提示未找到。
- 整局进度存在浏览器本地，刷新可恢复。**不收集账号、不上传个人信息、无需登录。**
- 所有密钥只在服务端读取，不进客户端产物（有自动化扫描持续验证）。

## 可以这样试

1. 打开 https://indeterminate.eilnoctis.com
2. 勾几个打算，写一句你自己的想法
3. 在序章点「看看知乎朋友们怎么推荐毕业后的选择」——注意每张卡片的作者和原文链接
4. 走完三次选择，留意每次结果里的**代价**和**仍然没有答案**
5. 到五年后，**回到第 8 天**（不是第 4 年），换一个做法
6. 看最后那三栏——尤其是「无法归因于你选择的」
